# CV Project Context

## Project Summary
A Streamlit web app for applying image processing filters manually (without using 
built-in CV library functions). Built for a computer vision class final project.

## Tech Stack
- Frontend/UI: Streamlit
- Image processing: NumPy (manual implementations), OpenCV only for reading/writing images
